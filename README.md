## Greenwood Public Library Website
This is a responsive library website created using HTML and Tailwind CSS. The website is designed to show library sections, membership plans, events, and other information. I created this project to practice Tailwind CSS, responsive layouts, grid systems and hover effects.

# Technologies used
- HTML
- Tailwind CSS

# Features
- Responsive design for middle, tablet, and desktop
- Sticky navigation bar
- Grid layouts
- Image zoom effects on hover
- Smooth hover transitions
- Membership cards
- Social media gifts

# How to run
- Download or open the project folder
- Open the folder in vs
- Open the index.html file
- Right click and select "open with live server"
